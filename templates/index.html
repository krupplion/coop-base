操作指引 · 结算单生成流程

按下列步骤完成「案件 → 提成判断 → 批量结算单 → 结案审批表」的端到端流程；自定义模板可复用，跳过该步骤不影响主流程。
  1. 录入/维护案件信息：前往「案件管理」录入案号、客户、代理费、结案月份等。状态流转支持 16 态（待接洽→咨询→签约→一审→执行→结案等）。
  2. 判断提成是否可结算：在「案件管理」工具栏点击「判断提成是否可结算」，系统按规则回填可结算月份；满足条件的案件在列表中以可结算绿色高亮。
  3. 批量生成薪酬结算单（Word）：在下方「① 一键生成结算文档」勾选可结算案件（绿色行已默认勾选），可选择结算模板，点击「一键生成结算文档」批量下载合并文档（每案一份《（ORG_NAME）案件结案审批表》，内含审批表 + 按成员薪酬结算单）。
  4. （可选）自定义结算模板：在「② 结算模板管理」新建模板，按 Word 模板四部分结构录入配置——第1部分案件基本信息（8 字段勾选/排序，生成时从案件管理自动带入）；第2部分案件办结情况（费用明细录入：收入填正数、垫付填负数 + 收益/提成自动计算实时预览）；第3部分审批意见（签字位姓名自动带入、日期默认生成日期）；第4部分说明（固定 5 条只读）。生成时切换模板即可生效。
注意：①结算一旦生成不可撤销，生成前请确认勾选无误；②自定义模板字段修改不影响已生成的 Word 文档；③同一案件同一结算月份重复结算会被拒绝。

① 一键生成结算文档（薪酬结算单 + 案件结案审批表合并）

勾选案件后点击「一键生成结算文档」：每案输出一份合并文档《（ORG_NAME）案件结案审批表》（审批表内容 + 按成员薪酬结算单内容合并，结算单部分按所选自定义模板渲染），打包 ZIP 下载，文档名称统一为「（ORG_NAME）案件结案审批表」。

批量录入（案件 / 花名册 / 客户）

上传 Excel / CSV，按字段映射（可选用导入模板）自动匹配至数据库，支持合并单元格内容自动填充；导入时自动清洗、校验并去重。人员花名册与客户信息可在对应页面批量导入。

本地离线 OCR 发票识别（推荐）

完全本地离线识别，数据不出本机。支持图片（JPG/PNG/BMP）与 PDF（文本型电子发票经 pdfplumber 精确提取，扫描件自动转图逐页识别），自动识别发票类型（专票/普票）、发票号码、购买方（客户名称）、项目名称（归集为费用科目）、金额、税额、开票日期，金额经误识别修正；销售方默认记「ORG_NAME」，识别不一致将标记待人工核对。

AI 电子发票识别（云端，可选）

上传发票图片，调用已配置的多模态 AI 识别并归集费用科目。支持火山引擎（豆包）、阿里百炼（通义千问）、腾讯云（混元）、兼容 OpenAI 四类云服务；密钥从环境变量或本地配置文件读取，不入库明文。

发票批量导入（多文件，推荐）

一次选择多张发票（图片 JPG/PNG/BMP 与 PDF 可混传），逐张自动识别并登记台账。文本型电子发票 PDF 经 pdfplumber 精确提取文本层，扫描件自动转图 OCR；识别失败或缺字段的发票会逐张提示原因，不会中断整批。识别要素：发票类型（专票/普票）、购买方（客户名称）、项目名称、价税合计、税额、开票日期。
