# coop-base · 律师局域网协同录入工作平台

> 基于 **Flask + SQLite** 的局域网多人协同录入工作平台（通用版），默认端口 `8100`，可直接部署使用，也可作为二次开发 / 功能验证的基线。

---

## 〇、项目概述

- 由一台电脑作为**本地服务器**，其余 2–3 位人员通过**浏览器**协同录入。
- 借助**局域网自动发现**（UDP 广播），客户端无需手动配置 IP / 端口即可连接服务器。
- 数据存储在本地 SQLite，**面向可信局域网内网使用**，不依赖公网。
- 后端单文件 `app.py`（数据模型、RBAC、全部 REST API、业务逻辑）；前端为零外部依赖的单页应用 `templates/index.html`（简洁风格）。

> 端口说明：Web 服务默认 `8100`，可用环境变量 `COOP_PORT` 修改；配网发现为 UDP `39997`（可用 `COOP_DISCOVERY_PORT` 修改）。

## 一、主要功能

1. **案件管理**：案号自动生成（如 `#260901`，格式 `#年两位月两位+序号`），记录开发人、负责人、小组成员、客户名称、代理费、代垫诉讼费、开票金额等，支持启用 / 停止 / 删除。
2. **薪酬计算**：按人员独立配置规则，支持**自定义公式**（变量 `agent_fee`、`court_fee_advance`、`invoice_amount`，函数 `min/max/round/abs`，沙箱求值，禁止任意代码）或固定金额 / 案件。
3. **批量结算单**：勾选案件 → 按人员逐案生成 Word 结算单 → ZIP 打包下载；支持可视化自定义模板（显示字段、顺序、标题与落款）。
4. **结案审批表**：按纸质审批表版式生成 Word（基本信息 → 费用收回明细 → 收益计算 → 提成明细 → 签字栏）。提成金额**展示完整计算过程**（`基数 × 比例 = 金额`），可追溯、可复核。
5. **导入导出**：Excel / CSV 导入自动清洗（去空白、金额 / 日期标准化）、去重、生成导入报告；一键导出台账；支持自定义「文件列名 → 系统字段」映射模板并复用。
6. **权限管理（RBAC）**：多角色登录、用户增停、密码重置；6 角色 + **角色 × 权限矩阵** + **用户级权限覆盖** + **系统设置页可视化配置**（勾选即持久化）。详见下文「二、用户角色与权限」。
7. **发票识别**：①**本地离线 OCR**（推荐）——基于开源 RapidOCR（PP-OCRv3 模型随包内置），识别发票号码、销售方、金额、税额、开票日期并按品名归集费用科目，**全程数据不出本机**；②云端 AI 识别（可选）——兼容 OpenAI 格式的多模态服务，执行严格字段映射与勾稽校验。
8. **人员花名册**：单位人员信息录入与维护，支持批量导入与格式校验。
9. **客户信息**：客户信息录入与维护，支持批量导入与校验。
10. **功能卡片**：工作台提供统一功能导航卡片，展示各模块名称、用途与操作入口。

## 二、用户角色与权限

系统内置 **6 个角色**（权限在服务端强制执行；前端隐藏按钮仅为体验优化）：

| 角色 | 标识 | 说明 |
|---|---|---|
| 财务经理 | `admin` | 最高权限：全部数据、用户、系统配置、日志 |
| 财务专员 | `finance` | 案件财务字段、薪酬、结算单、发票识别 |
| 案件专员 | `case` | 案件基本信息录入与维护 |
| 查看人员 | `viewer` | 只读查看案件台账 |
| 机构负责人 | `institution_head` | 机构全局管理：查看全部数据、审批结案、管理本机构人员与角色 |
| 律师 | `lawyer` | 案件基本信息录入与维护，可查看 / 编辑参与的案件 |

**权限矩阵（16 项）**：`case.view / case.edit / case.finance / case.stop / case.enable / case.delete / salary.view / salary.edit / settle.view / settle.edit / file.import / file.export / invoice.edit / user.manage / log.view / setting.manage`。

**可视化配置**：系统设置页提供「人员角色权限管理」卡片（角色 × 权限勾选矩阵），保存后写入 `data/role_config.json` 并**立即生效**；在用户管理页可给单个用户单独分配权限（留空则继承角色默认）。配置过程带保存确认与容错回滚，且强制保证 `setting.manage` 始终含 `admin`，防止误操作锁死系统。

## 三、多人协同：同步机制与冲突处理

- **数据库层**：SQLite WAL 模式 + `busy_timeout`，支持多人同时读写不报错。
- **应用层（乐观锁）**：每条案件记录带 `version` 版本号；编辑时提交 `base_version`。
- **冲突策略（字段级合并 + 最后写入优先）**：
  - 保存时若他人已先保存（版本过期），系统自动**合并**本次修改的不同字段；
  - 同一字段被两人先后修改时**最后写入优先**，被覆盖旧值完整写入操作日志（可追溯、可人工恢复）；
  - 保存后前端提示「检测到他人同时修改，已合并」。

## 四、操作日志（审计追溯）

所有增删改查、登录、导入导出均写入 `audit_logs` 表，记录：操作用户、时间、动作、对象类型、对象标识、变更详情、来源 IP。财务经理 / 机构负责人可在「操作日志」页面检索。

## 六、本地运行（开发 / 测试）

### 1. 环境准备
- Python 3.10+（本机已配置隔离环境，无需全局安装）
- 安装依赖（仅需一次）：
  ```bash
  pip install -r requirements.txt
  ```

### 2. 启动服务器
```bash
python app.py
```
启动后控制台显示：
- 访问端口：**8100**（可用环境变量 `COOP_PORT` 修改）
- 默认账号：**admin / 123456**（首次登录请立即修改）

> 防火墙提示时请选择「允许访问」（专用网络）。若其他电脑连不上，请在 Windows 防火墙放行入站端口 **8100（TCP）** 与 **39997（UDP）**。

### 3. 其他人员连接（自动配网）
1. 将 `client_connect.py`（或 `client_connect.bat`）拷贝到各人电脑
2. 双击运行，输入服务器分发的配网标识
3. 程序自动在局域网内发现服务器并打开浏览器——无需知道 IP、端口

## 八、打包发布

`build.bat` 一键完成完整打包链路：调用 PyInstaller 将服务与客户端分别打包为 `dist\server\server.exe` / `dist\client\client.exe`，再用内置便携版 NSIS（`install\nsis\makensis.exe`）据 `install\coop.nsi` 生成安装程序 `out\setup_coop.exe`。重新打包时**只需双击 `build.bat` 一次即可**，无需手动跑 NSIS。

前置条件：
- 已安装 Python 虚拟环境 `.venv`（含 flask / rapidocr-onnxruntime / pdfplumber / pymupdf 等全部依赖，见 `requirements.txt`）。
- 离线 OCR 模型、PDF 字体/编码表（pdfminer cmap）、字典等资源均已随依赖打包进 exe，断网可正常运行。
- 应用图标为 `install\app.ico`（天平+法典+公文，蓝白配色，7 档尺寸）；安装包与快捷方式图标均取自该文件。

安装包产物：`out\setup_coop.exe`（约 102 MB，管理员权限安装，默认目录 `C:\Program Files\协同录入系统`，Web 端口 8100 / 配网 UDP 39997）。安装完成后自动启动服务器并打开「操作简介.html」，并在桌面 / 开始菜单 / 启动项创建快捷方式。

## 九、安全提示

- 本系统面向**可信局域网内网**使用，请勿直接暴露到公网。
- 默认密码务必修改；AI 密钥仅存储于服务器本地数据库 / 配置文件。
- 密码哈希为 SHA-256 加盐存储，适用于内网场景；如需更高强度可替换为 bcrypt。
- 仓库已通过 `.gitignore` 排除运行数据（`data/`）、密钥（`.env`、`ai_providers.json`）、数据库（`*.db`）及构建产物，上传代码不含业务数据。
